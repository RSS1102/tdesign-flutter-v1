6/// `TDateTimePicker` 内部的**不可变状态快照**（@internal，业务侧无需关心）。


7///


8/// 替代旧设计中并行存在的 `_current` / `_initialValue` / `_pickerColumns` /


9/// `_lastValues` 四字段——它们之间任何一个落后/超前都会引发 bug。新设计把


10/// 「列结构 + 当前选中 DateTime」收敛到一个 immutable value object 内：


11///


12/// - 任何中间派生值（picker initial values / picker columns / 回调结果）


13///   都是 snapshot 的派生方法，单一真相源；

279      final col = columns[i];

377        case DateTimeColumn.month:
