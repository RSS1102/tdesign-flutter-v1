
## 工作耗时计划表生成

根据用户需求，基于以下资料制作了 TDesign Flutter V1.0 升级项目的工作耗时评估表：
- `.codebuddy/plans/` 下 14 份计划文件（含各分类组件升级方案、Theme 重构、自动化验收等）
- `docs/v1.0/` 各组件定稿文档（5 大分类共 60+ 组件）
- 用户上传的 TEG 设计项目工时评估 Excel 截图作为格式参考
- 近期工作记忆（2026-07-09, 2026-07-10）中的测试覆盖率数据和修复记录

**产出**：HTML 可视化工时表（已通过 show_widget 展示），包含：
- 7 大模块：基础设施 / 基础组件(6) / 导航(8) / 输入(18) / 数据展示(17) / 反馈(11) / 收尾保障
- 5 列工时：PM / 前端开发 / 前端联调 / 测试 / 备注（已去掉后端列）
- 总计：PM 12.25天 / 前端开发 77.75天 / 前端联调 33天 / 测试 36.5天 ≈ **前端合计 147 人天**

## 工时评估表优化（第二版）
在 2026-07-14 首版工时表基础上按用户要求优化：
- 删除「前端联调」列
- 「前端开发」「测试」两列中原始值 ≥1 的：折半并保留 1 位小数（<1 保持原值）
- PM、备注列不变
- 未生成 Excel（用户要求暂缓）
产出 HTML：tdesign-component/docs/v1.0/TDesign_Flutter_V1_0_工时评估表_优化版.html
优化后合计：PM 18.3 / 前端开发 47.0 / 测试 27.2 / 前端合计 ≈74.1 人天

## 工时评估表量化（v3）
在 v2 基础上追加量化规则（作用于前端开发/测试两列）：
- 当前值 >0.5 且 <1 → 0.5；>1 且 <1.5 → 1（等于0.5/1/1.5不动）
- PM、备注仍不动
结果：PM 18.3 / 前端开发 42.8 / 测试 23.5 / 前端合计 ≈66.3 人天
文件覆盖：tdesign-component/docs/v1.0/TDesign_Flutter_V1_0_工时评估表_优化版.html
